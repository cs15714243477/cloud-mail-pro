# 邮件客户端说明

Cloud Mail Pro 提供 Web 邮箱和 HTTP API。它没有提供可供 Outlook、Thunderbird 等客户端直接连接的 IMAP、POP3 或 SMTP 服务器端口。

如果需要传统客户端收发邮件，需要另外配置具备这些协议的邮件服务器，并自行设计与 Cloud Mail Pro 的数据或发件集成。External API 不等同于 SMTP 服务。
